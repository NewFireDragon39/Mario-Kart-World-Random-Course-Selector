# Mario Kart World Random Course Selector
Have you ever wanted to pick a random course in Mario Kart World without Routes? Well now you can!

> [!IMPORTANT]
>Mario Kart World is a video game developed and published by Nintendo. Mario Kart World Random Course Selector is not affiliated in any way with Mario Kart World or Nintendo. Mario Kart World is a registered trademark of Nintendo of America Inc.

## Requirements

Executable:  
Python 3.6+  

Shortcut:  
iOS 12.0+, iPadOS 12.0+, macOS 12.0+ (Monterey or later), watchOS 12.0+*, visionOS 1.0+*

*watchOS and visionOS have not been verified.
